# Code for "Spatial Disaggregation with Changing Areal Boundaries"

This repository reproduces the examples in the paper. The method is
implemented in the R package **DAST**, available from CRAN:

```r
install.packages("DAST")
```

**Start here:** [`vignette_manchester.pdf`](vignette_manchester.pdf) is a
worked example covering data download, preparation, pre-fit checks, model
specification, fitting, outputs, interpretation, common problems and a
template for applying the method to new data. It is the paper's
Supplementary Material.

## Contents

| File | What it is |
|---|---|
| `vignette_manchester.Rmd` / `.pdf` | Worked example (paper Section 5 and Supplementary Material): under-5 mortality in Greater Manchester, 2008--2012, across the 2011 LSOA boundary revision |
| `R/download_helpers.R` | Retrying download helpers used by the worked example |
| `disagg_EU.Rmd` | Belgium--Netherlands example (paper Section 4): under-5 mortality by NUTS-3 region, 2015--2023, three NUTS boundary sets |
| `final_manchester_2008_2012.Rmd` | The Manchester analysis as generated by an AI coding assistant (Codex) and then debugged, kept unchanged as a record. It contains errors in data assembly, which the worked example corrects and documents (see its final section) |
| `final_manchester_2008_2012_cran.Rmd` | The same file, changed only to install DAST from CRAN |
| `data/` | Downloads and frozen inputs are written here (not version-controlled) |

## Running the examples

All examples download their data on the first run and need an internet
connection. The worked example needs about 5 GB of free disk space, mostly
for the 100 m WorldPop rasters.

**Worked example (Manchester).** From the repository root:

```r
rmarkdown::render("vignette_manchester.Rmd", output_format = "pdf_document")
```

This produces `vignette_manchester.pdf`. Processed inputs are frozen as
date-stamped `.rds` files in `data/manchester/` and are reused on later runs.
Delete them to download fresh data.

Required packages: `DAST`, `aghq`, `sf`, `terra`, `mapmisc`, `dplyr`,
`ggplot2`, `readxl`, `jsonlite`, `data.table`, `rmarkdown`, `knitr`.

**Belgium--Netherlands example.**

```r
rmarkdown::render("disagg_EU.Rmd", output_format = "pdf_document")
```

This example additionally needs `eurostat`, `geodata`, `Pmisc` and
`Matrix`.

## Notes on reproducibility

* Statistical agencies revise their published tables. ONS supplies the
  Manchester deaths on 2011 LSOAs for every year, and Eurostat has re-coded
  Belgian counts from 2017 onwards to NUTS 2021. Each example documents the
  boundary vintages it uses and the date the data were extracted.
* Neither example relies on the knitr cache. Render from a fresh R session.
